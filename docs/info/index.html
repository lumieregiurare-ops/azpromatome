アズールプロミリアの基本情報

タイトルアズールプロミリア（Azur Promilia）
ジャンル星霊と旅するファンタジーワールドRPG
配信日2026年11月26日（木）
対応機種iOS / Android / PC（Windows）
価格基本プレイ無料（アイテム課金）
開発Manjuu Games（『アズールレーン』の開発元）
運営Manjuu Games・Yostar（日本国内は共同パブリッシング）
年齢区分App Store 12+
同日配信日本・韓国・台湾・中国
容量（App Store）3.4GB

プレイヤーは予言された「星臨者」としてプロミリア大陸に降り立ち、仲間と一緒に災厄に立ち向かう。大陸のあちこちにいる幻想的な生きもの「キボ」と絆を結び、キボと協力して農園を管理しながら、敵と戦い、大陸に眠る謎を追いかける。

用語

星臨者
プレイヤーキャラクター。予言された存在としてプロミリア大陸に降り立つ。CV は森永彩斗さん・田村好さん。
キボ
大陸の各地に住む幻想的な生きもの。絆を結ぶと冒険や農園作りを手伝ってくれる。
アニマ
キャラクターに装備して能力を上げるもの。専用のガチャ「絆心の観測」「恒序観測」がある。
農園
キボと協力して管理する。スローライフの要素。
寮
仲間と暮らす場所。「寮セット」で内装と寮内のキャラクタースキンを変えられる。
無垢な痕跡
ガチャに使うアイテム。事前登録の達成報酬で合計20枚配られる。
観測
ガチャのこと。限定キャラの「星弦の観測」、常設の「恒常観測」、初心者向けの「始源の観測」などがある。
